Fractadyne vs Kalles Fraktaler — reference render corpus

Twenty locations, ordered by magnification from the full-set overview to 6.13e1105×, rendered by both apps from the exact same center / magnification / iteration cap for side-by-side structural comparison. Fractadyne renders (all twenty) come from generate_corpus.py; the Fraktaler-3 side from generate_fraktaler.py. With maximum_reference_iterations set in each F3 param (see README — F3’s batch default is far too low for a zoomed view and blanks silently, which long masqueraded as a ~1e13× ceiling), F3 renders deep correctly here: all 20 locations have clean, arm-for-arm F3 counterparts, out to 6.13e1105× (over a thousand orders of magnitude). The former 1e30× gap (location 07, once a too-coarse 34-digit seahorse placeholder that F3 rounded onto different sub-structure) is now a genuine cross-app match, re-imported from a user Fraktaler-3 save with a 43-digit center. Locations 07 and 11–20 are user-saved Fraktaler-3 finds (1e30× to 1.58e1008×), imported from their .exr headers with center, zoom, and iteration count taken verbatim. Coloring note for the deep dendrite / minibrot views (13, 14, 15, 16–20): at these depths the smooth-iter counts are huge (~3e5–1.6e6+) and vary steeply pixel-to-pixel, so the fixed palette cycle (0.27) aliases a correct escape field into speckle (long mis-diagnosed as glitches, then a perturbation bug — both wrong; a faithful CPU transcription of the mode-2 shader kernel reproduces the escape VALUES exactly). These renders use auto-normalized coloring (--normalize: the frame's escape range mapped to the palette), which colours the smooth exterior cleanly and matches F3 arm-for-arm. The spiral views (09–12) have slowly-varying exteriors that don't alias, so they keep the standard cycle. The general fix — an adaptive-cycle coloring mode for the live view — is in TODO.md. 15 also needed a rendering fix (v0.2.18): its right-side dendrites escape at 928k–1.6M — past the reference orbit (~918k) — so they must rebase at the reference’s near-zero orbit dips. The GPU’s BLA-skip path was skipping those dips without a rebase check (it assumed δz stays small in the BLA regime, which fails where |Z|≈0), marching the deep pixels to the reference end and capping them at ~919k so the dendrites vanished. A rebase check at the BLA landing restored the full range (this also sharpened the deep-centre detail of 11–13); goldens stayed byte-identical.

Reading the comparison: palettes and smooth-coloring curves differ between the apps by design — compare structure (feature placement, spiral arm counts, escape-boundary shape, minibrot positions), not colors. Zoom note: Fractadyne’s magnification equals the Kalles Fraktaler / Fraktaler-3 zoom (both reference a 4-unit vertical extent at value 1; aligned in v0.2.21) — the same zoom number frames the same view in either app.
