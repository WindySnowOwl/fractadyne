Fractadyne vs Kalles Fraktaler — reference render corpus

Ten locations from the full-set overview to 4.6e1105×, rendered by both apps from the exact same center / magnification / iteration cap for side-by-side structural comparison. Fractadyne renders (all ten) come from generate_corpus.py; the Fraktaler-3 side from generate_fraktaler.py. With maximum_reference_iterations set in each F3 param (see README — F3’s batch default is far too low for a zoomed view and blanks silently, which long masqueraded as a ~1e13× ceiling), F3 renders deep correctly here: locations 01–06 and 08–10 have real, arm-for-arm F3 counterparts, out to 4.60e1105× (over a thousand orders of magnitude). The lone gap, 07 (1e30×), is a center-precision placeholder — its 34-digit seahorse center is too coarse for a reproducible cross-app match there, while 08 (83-digit), 09 (526-digit) and 10 (1141-digit) carry far more digits and match far deeper.

Reading the comparison: palettes and smooth-coloring curves differ between the apps by design — compare structure (feature placement, spiral arm counts, escape-boundary shape, minibrot positions), not colors. Framing note: Fractadyne’s magnification is referenced to a 3-unit-high view; KF’s zoom is referenced to its own (wider) home frame, so KF may frame the same zoom value slightly wider — the center feature and structure must still match exactly.
