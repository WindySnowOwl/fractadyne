Mandelbrot set
Escape-time · parameter plane of the Julia family
Formula
zn+1 = zn² + c
z₀ = 0, c = pixel
Description

The set of complex numbers c for which the orbit of 0 under z² + c stays bounded. Its boundary is infinitely intricate and self-similar, and contains a miniature copy of itself at every scale — the source of endless deep-zoom structure.

History

Named after Benoit Mandelbrot, who studied it at IBM in 1980; first plotted by Brooks and Matelski in 1978.

Parameters
power exponent in zⁿ + c (2)
bailout escape radius² (256)
